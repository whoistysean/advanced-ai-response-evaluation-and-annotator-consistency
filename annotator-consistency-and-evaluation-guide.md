Annotator Consistency and Evaluation Guide

1. What Is Annotator Consistency?

Annotator consistency means applying the same evaluation standards across different AI responses and tasks.

An evaluator should not change their judgment simply because one response is longer, sounds more confident, or uses more impressive language.

2. Core Evaluation Principles

Follow User Instructions

Check the exact requirements, including:

* Requested number of items.
* Required format.
* Intended audience.
* Language complexity.
* Requested length.

Evaluate Objectively

Base decisions on evidence and evaluation guidelines rather than personal preferences.

Separate Evaluation Criteria

Assess each criterion independently:

* Factual Accuracy: Is the information correct?
* Relevance: Does it answer the question?
* Completeness: Does it provide all required information?
* Clarity: Is it understandable?
* Instruction-Following: Does it obey the user’s explicit requirements?

3. Common Evaluation Mistakes

* Assuming longer responses are always better.
* Rewarding unnecessary information.
* Ignoring exact quantity requirements.
* Confusing relevance with completeness.
* Allowing personal preferences to influence rankings.
* Treating technically correct information as automatically instruction-compliant.

4. A Consistent Evaluation Process

1. Read the user’s prompt carefully.
2. Identify every explicit instruction.
3. Evaluate each response against the same criteria.
4. Identify strengths and weaknesses.
5. Compare the responses objectively.
6. Rank the responses.
7. Explain the decision using specific evidence.

5. Writing Professional Evaluation Feedback

Good evaluation feedback should:

* Identify the specific issue.
* Explain which instruction or criterion was affected.
* Avoid vague judgments.
* Remain objective and concise.

Example:

“Response B provides relevant information but lists five benefits instead of the two requested. Response A follows the requested quantity and brevity more accurately, so it should receive the higher ranking.”

Conclusion

Reliable AI evaluation depends on consistency, objectivity, and careful application of evaluation guidelines. Annotators should judge responses against the user’s actual requirements rather than personal preferences or response length.
